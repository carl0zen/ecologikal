```

├── README.md                 ← you are here
```

## Design intent

- **CLAUDE.md** = always-on compass (short)
- **product / knowledge** = durable truths (edit carefully)
- **living** = changing map + session memory (edit freely)

If docs disagree with code, **code + SQL win** — then fix the docs via EVOLVE.

# Product Vision — Ecologikal

## Pitch

Ecologikal is an **eco + social network** that turns ecological participation into a structured game of connection: earn **KINS**, travel to **eco-centers**, protect **ecozonas**, publish useful knowledge by **petal**, and meet **econautas** matched by skill — not vanity metrics.

Origin context: ~2011–2012, Spanish-first (Monterrey), aligned with the Global Ecovillage Network (GEN) educational “petals.”

## Why it still matters

Modern platforms fragment what Ecologikal tried to unify:

| Platform pattern | Ecologikal counterpart |
|------------------|------------------------|
| Facebook infinite scroll | Six **intent modes** (Play / Travel / Discover / Learn / Meet / Cooperate) |
| LinkedIn skills | **7-petal flower** + peer references (competence attested by community) |
| Meetup events | Workshops + vacancies on **eco-center** orgs |
| Airbnb / Workaway / WWOOF | Eco-center venue with lifestyle rules + booking + volunteering + KINS |
| Nextdoor local | **Place → Need → cooperative labor** with visible donors |
| Generic likes | **Amplificate / Broadcast** (boost vs reshare) |
| Check-ins | Collaborative **travel diary** with skills + friends + stops |

The innovative core is not “another social network” — it is an **operating system for regenerative participation**.

## Six pillars (user modes)

| Mode | Promise (from `index.php`) | Durable idea |
|------|----------------------------|--------------|
| **Juega** | KINS as ecosocial currency for actions | Earn by contributing; spend on stays, workshops, eco-products |
| **Viaja** | Travel diary + eco-centers | Eco-hotels / hostels / ecovillages as first-class venues |
| **Descubre** | Share ecozonas; surface ecosocial needs | Place stewardship + mutual-aid needs on a map |
| **Aprende** | Online time should be useful | Knowledge filtered by petal categories only |
| **Conoce** | Find econautas by skill | People discovery via flower, not keyword spam |
| **Coopera** | Expert volunteering via skill match | Vacancies/recompenses tied to petals (entry missing) |

## Core journeys

1. **Onboard** — email → interests (“red semántica”) → skills-by-petal sliders → profile → bonds
2. **Become visible** — flower grades grow via skills + peer references → KINS accrue
3. **Discover action** — place/need near you → follow / participate / fund with KINS
4. **Learn** — petal-filtered ideas/articles/workshops → Amplificate / Broadcast
5. **Travel** — plan trip with stops + invite friends with required skills → book eco-center
6. **Cooperate** — match vacancy skills to flower → volunteer → earn KINS

Account types in registration views: **member / ecocenter / event / project**.

## Still-innovative product ideas (salvage priorities)

Ranked for greenfield relevance:

1. **Petal OS** — one taxonomy for skills, content, hiring, and filters (GEN-native)
2. **Flower reputation** — visual, peer-attested competence vs résumé spam
3. **Place → Need → Labor + micro-currency** loop for local restoration
4. **Eco-center org profile** — culture constraints (diet, alcohol, spirituality) + ops
5. **Amplify/Broadcast** — intentional signal economics without dopamine likes
6. **Game board as discovery** — actions as playable moves with KINS deltas
7. **Skill-intent travel** — trips as social objects with capability requirements
8. **Semantic onboarding before feed** — personalize for impact, not ads

## Non-goals (for agents)

- Recreating 2012 Facebook chrome
- Treating mock Monterrey feed data as product truth
- Expanding decorative nav items without a domain path
